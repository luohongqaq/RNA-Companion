# tokenizer 来源说明

本目录的 tokenizer 文件（`tokenizer.json`、`tokenizer_config.json`）来自 DeepSeek
开源发布的 V3 系列 tokenizer，按 [MIT License, Copyright (c) 2023 DeepSeek](https://github.com/deepseek-ai/DeepSeek-V3/blob/main/LICENSE-CODE)
分发，此处仅作本地 token 计数使用，未做修改。

目录名中的 "v4" 是本项目引入时的内部叫法；文件本体与 DeepSeek V3 公开发布的
tokenizer 一致。
