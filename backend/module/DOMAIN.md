# 功能模块领域数据导航

各功能按业务流程解释数据的来源、用途和代码位置：

- [聊天](chat/DOMAIN.md)：会话、消息、回复任务、提示词和场景。
- [角色](character/DOMAIN.md)：角色卡、提示词版本和视觉资源。
- [模型设置](model_settings/DOMAIN.md)：保存值、有效值和更新请求。
- [上下文压缩](context_compaction/DOMAIN.md)：冻结来源、摘要、快照和继承。
- [记忆管理](memory_management/DOMAIN.md)：日记、事件对象、主题及生产任务。
- [记忆召回](memory_recall/DOMAIN.md)：候选、已读材料、缓存和选择结果。
- [用户查询与编辑](user_edit/DOMAIN.md)：公开正文、编辑命令和索引状态。
- [共享能力](shared/DOMAIN.md)：跨模块的上下文、记忆、任务与通用契约。

模块关系见 [ARCHITECTURE.md](ARCHITECTURE.md)。
