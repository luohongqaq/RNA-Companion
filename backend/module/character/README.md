# 角色

角色模块提供角色列表与详情、角色卡和提示词的读取与编辑，以及背景、立绘资源的查询和匹配。聊天回复、记忆选择和上下文压缩可以使用角色卡或其投影。

- 启动时从 `resources/characters/*/manifest.json` 发现并登记角色。
- 查询角色资源清单和已登记图片。
- 读取、按版本保存角色卡、系统提示词和语气提示词。
- 根据服装、姿势和表情匹配立绘，找不到精确组合时按顺序回退。
