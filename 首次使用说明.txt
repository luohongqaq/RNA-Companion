RNA Companion 首次使用说明
============================

RNA Companion 是本地运行的 AI 陪伴桌面应用：聊天记录、记忆数据全部保存在本机文件夹内，
对话模型通过你自己的 API key 接入（GLM / DeepSeek 等 OpenAI 兼容服务）。

先确认你属于哪种情况
--------------------
- 从发布页下载了便携版 zip（里面有 RNA Companion.exe）→ 按本文档走，共 5 步。
  下载地址：https://github.com/luohongqaq/RNA-Companion/releases
- clone 的是源码仓库（没有 exe）→ 请看 README 的「快速开始」，
  用 npm run electron:dev 启动；本文档第 2、3 步对应的两个 bat 同样可用。

首次使用共 5 步，约 10 分钟（其中模型下载 3.3 GB 取决于网速，只做一次）。

--------------------------------------------------------------------
第 1 步：安装 Python 3.12（只做一次）
--------------------------------------------------------------------
打开 https://www.python.org/downloads/release/python-31210/
下载 "Windows installer (64-bit)"，安装时务必勾选 "Add python.exe to PATH"。

--------------------------------------------------------------------
第 2 步：双击 安装依赖.bat
--------------------------------------------------------------------
会在 backend\ 下创建虚拟环境并安装后端依赖（几分钟）。

--------------------------------------------------------------------
第 3 步：双击 下载模型.bat
--------------------------------------------------------------------
从 ModelScope 下载两个本地模型（BGE-M3 与 Qwen3-Reranker，共约 3.3 GB），
存放在 backend\models\ 下。支持断点续传，中断后重新运行即可。

--------------------------------------------------------------------
第 4 步：配置 API key
--------------------------------------------------------------------
1. 进入 backend\ 目录，复制 .env.example 重命名为 .env（可用记事本编辑）
2. 填入两组 key（在对应服务商官网申请）：
   - RNA_REPLY_API_KEY     回复模型，默认智谱 GLM（https://open.bigmodel.cn）
   - DEFAULT_API_KEY       记忆筛选/总结的回退模型，默认 DeepSeek（https://platform.deepseek.com）
启动后也可以在应用内"模型设置"页修改，会自动写回 .env。

--------------------------------------------------------------------
第 5 步：双击 RNA Companion.exe
--------------------------------------------------------------------
第一次启动会初始化本地数据库（backend\memory_record\），随后自动进入聊天界面。
你对话的第一句话会发给 deepseek（默认角色）。

--------------------------------------------------------------------
如何更新应用
--------------------------------------------------------------------
新版本发布后，应用启动时会自动检测并在顶部提示。手动更新步骤：
1. 从发布页下载新版 zip，解压到一个新文件夹
2. 把旧文件夹 backend\ 中的以下四项复制到新文件夹的 backend\ 内：
   - .env            （你的 API key 配置）
   - .venv           （虚拟环境）
   - models          （本地模型）
   - memory_record   （聊天与记忆数据）
3. 双击新文件夹里的 RNA Companion.exe
确认新版一切正常后，旧文件夹即可删除。

--------------------------------------------------------------------
常见问题
--------------------------------------------------------------------
- 双击 exe 提示后端启动失败：确认 .env 已配置、第 2/3 步已完成；
  更多原因见 backend\memory_record\database\logs 下的应用日志。
- 聊天有回复但很慢：回复速度取决于你使用的模型服务商。
- 没有 NVIDIA 显卡：在 .env 中把 RNA_MEMORY_RERANKER_DEVICE 改为 cpu。
- 更换对话模型：.env 中改 RNA_REPLY_BASE_URL 为任何 OpenAI 兼容接口地址。
- 想修改角色设定：编辑 backend\resources\characters\character_deepseek\ 下的
  角色卡.md 等文本文件，重启应用生效。

--------------------------------------------------------------------
卸载
--------------------------------------------------------------------
删除整个文件夹即可，不会在系统里留下任何残留。
